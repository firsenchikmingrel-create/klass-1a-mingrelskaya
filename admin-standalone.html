Вход владельца

Введите fine-grained GitHub token с доступом только к репозиторию klass-1a-mingrelskaya и разрешением Contents: Read and write. Ключ не сохраняется постоянно — только до закрытия вкладки.

🔐 Сам токен в код сайта не записывается и в GitHub не публикуется. Админка не подключает сторонние скрипты и не передаёт ключ куда-либо, кроме api.github.com.
